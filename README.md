# Calculadora de Hábitos

Una pequeña web app para crear, marcar y eliminar hábitos diarios.  
Guarda tus hábitos automáticamente usando `localStorage`.

## Tecnologías
- HTML
- CSS
- JavaScript

## Cómo usar
1. Abrir `index.html` en tu navegador.
2. Escribe un hábito y presiona "Añadir".
3. Haz clic sobre el hábito para marcarlo como completado.
4. Haz clic en "Eliminar" para borrar un hábito.
